# 16×16 像素贴图绘制 SOP

本规范适用于 Poiesis 的物品图标、部件图标和其他需要原生像素风格的低分辨率贴图。

## 画布与绘制

- 必须直接创建 **16×16 像素**画布；每个网格像素就是 1×1px。
- 逐像素绘制，使用硬边铅笔或等效的单像素工具，不使用笔刷平滑。
- 禁止先绘制大图再缩小，也禁止任何插值、抗锯齿、模糊、锐化或滤镜处理。
- 透明背景保留为完全透明；图标边缘不得用半透明抗锯齿像素软化。
- 颜色使用有限的手工调色板，保留清晰的明暗层次和 Minecraft 物品图标的硬边轮廓。

## 资源输出

- 直接输出到 `src/main/resources/assets/poiesis/textures/item/<item_id>.png`。
- 使用带透明通道的 PNG；图标主体应留出适当边距，避免贴边或越界。
- 文件名使用注册用的物品 ID，小写并以下划线分词。
- 需要预览时可以临时用最近邻放大，但放大的预览不能替代或覆盖原始 16×16 资源。

## 交付检查

1. 图像尺寸必须为 16×16。
2. 透明区域仍为透明，不能被背景色填充。
3. 像素边缘无半透明插值和模糊痕迹。
4. 物品模型直接引用该原生贴图，不再额外缩放或重采样。
5. 生成后检查游戏内物品栏、手持和 JEI 显示，确认像素边缘保持锐利。
