# Poiesis TODO List

## 工业缓冲仓

定位：产线之间的中转与安全断点，不是单纯扩大容量的箱子。

### 物料缓冲仓

- 储存物品，但不参与加工。
- 支持输入、输出、输入输出三种方向配置。
- 支持物品过滤、红石暂停和最低保留量。
- 支持顺序输出、平均分配和优先级输出。
- 管道断开或中途被破坏时，仓内物品不会凭空消失。

### 流体缓冲罐

- 使用多个独立液槽，避免不同流体合并显示或互相污染。
- 支持流体锁定、自动输入、自动输出和最低保留量。
- 多个输出分支支持平均分配或优先级分配。
- 适合连接气化炉、吸附塔、浸取机和温室等大流量设备。

### 工业定位

- 解决上游生产过快、下游暂时停机、换配方和管道断开的产线问题。
- 不提供加工能力，不替代仓库或大型存储模组。
- 可使用白铬外壳、重型机械外壳、石墨板和耐热钢等现有材料制造。
- 核心价值是提高整条生产线的稳定性，而不是单纯提高机器性能。

## 后续开发提案

### 模块零件化装配体系

定位：将专业化模块和性能模块从“基板 + 少量材料”的直接合成，逐步改造成具有工程记忆点的零件装配体系。

设计原则：

- 不为每个模块单独制造一套小零件，优先建立少量可复用的通用零件。
- 零件应能同时服务于模块、发电机、IO设备、管道组件和未来多方块结构。
- 模块基板负责承载，通用零件负责控制、接口和能量连接，工艺组件负责决定具体功能。
- 先用于新模块，后续再随着配方重做逐步迁移已有模块，避免一次性大规模改动。

候选通用零件：

- **控制核心（Control Core）**：模块和自动化设备的逻辑控制部件。
- **机器接口（Machine Interface）**：负责模块与机器之间的安装、数据和能力连接。
- **能量耦合器（Power Coupler）**：负责能量输入、转换和调节，可复用于性能模块与发电机组件。
- **工艺组件（Process Assembly）**：按机械、流体、电化学、热工等方向复用，而不是为每个模块独占。
- **精密校准件（Calibration Unit）**：用于高级模块、检测设备和重型机械的精密调校。

建议的第一阶段只引入控制核心、机器接口和能量耦合器；滤板、石墨电极、石墨板、纤维复合料等现有材料暂时承担工艺组件的作用。后续随着大型车床、真空脱气仓和电化学设备的发展，再补充专用工艺组件。

### ~~端点驱动管网提案（Endpoint-Driven Pipe Network，EDPN）~~（已完成）

定位：Poiesis 物品、流体、能量管网的后续重构基线。

核心原则：

- 抽取端驱动调度，普通管段只维护拓扑，不逐管执行传输。
- 缓存输入端、输出端与必要路径；仅在拓扑、端点模式、能力或区块状态变化时失效。
- 严格执行 INSERT / EXTRACT / DISABLED 的能力方向，不允许外部设备绕过端点模式。
- 使用可验证的模拟、执行和回滚流程，任何回滚失败都不得静默吞掉资源。
- 同时轮换源端、源槽位/储罐和目标端；轮询状态以稳定端点标识保存，网络重建后尽量延续。
- 速率以管道等级为唯一数据源；优先采用“每个抽取端额度 + 每网络操作上限”。
- 保留瞬时传输和无在途实体的设计，拆管时不产生在途资源丢失。

借鉴方向：Pipez 的抽取端调度，XNet 的端点缓存、严格方向、优先级与轮询，Ender IO 的路径瓶颈；不引入 XNet 式控制器和复杂频道系统。

### ~~模块化吸附塔提案（Modular Adsorption Column，MAC）~~（已完成）

定位：远期多方块流体净化设备，当前阶段暂不开发。

核心加工：含杂质流体 + 吸附介质 -> 净化流体 + 饱和吸附介质。

结构设想：底部控制基座、可变数量的中间吸附床层、顶部流体分布器；仅基座持有方块实体和资源。

结构规模：最小为基座 + 2 层吸附床 + 顶部，可设置最大高度。

结构意义：床层数量影响介质容量、流体缓存、吞吐量和高级配方的最低结构要求，但速度收益应受基座能力限制。

IO 原则：顶部输入待净化流体，基座负责能源、吸附介质、饱和介质和净化流体输出。

安全原则：结构破坏只解除成型状态，所有流体和物品仍保存在基座，不得丢失。

配方原则：通过独立流体种类定义净化前后状态，不建立基于 FluidStack NBT 的通用杂质数值系统。

材料衔接：未来可考虑使用红麻芯制备生物质活性炭，但不能因此制造现有流程的循环依赖。

### 真空脱气净化仓（Vacuum Degassing Chamber）

定位：通过低压环境去除液体中的溶解气体、微小气泡和挥发性杂质的后期多方块设备。

核心加工：含气工艺液 -> 脱气净化液 + 废气或挥发物。

结构设想：密封仓体、真空泵、控制器、液体入口、净化液出口和废气出口；仓体规模可以影响处理容量与真空稳定性。

工业意义：与吸附塔、过滤设备和蒸馏设备形成明确分工，不吸附化学污染物，专门解决液体中的气体问题。

应用方向：为微生物燃料电池提供脱氧阳极液，为电积和催化反应提供无气泡工艺液，也可作为高纯白铬浆液处理的前置设备。

### 微生物燃料电池：可编程电化学组件

当前 MFC 内置一套默认电化学配置，使基础配方无需专业化升级即可运行。

未来专业化系统包含四个可替换部分：

- 阳极：影响有机底物适应性、反应效率与耐久方向。
- 阴极：影响氧化还原效率、峰值发电功率与阴极液适应性。
- 隔膜：影响离子传导效率、流体交叉污染和长期稳定性。
- 菌群：决定可利用的阳极液种类、基础产能和环境耐受性。

四项组件由一个完整的电化学专业化模块承载；未来可在编程台修改模块内部配置，不在 MFC GUI 中增加四个独立物品槽。

## 自然与生态扩展候选

这些内容作为 Poiesis 后续世界内容的候选方向记录，暂不视为确定开发项目。新增自然内容应至少与生物工业、环境工业、重工业或精炼工业中的两个系统产生联系，并且不通过独占资源绕过现有流程。

### 植物候选

- **芦苇**：湿地植物，可作为生物质、纤维和过滤材料来源，连接气化炉、环境处理和湿地生态。
- **桤木**：固氮树种，可改善土壤肥力，并提供木质生物质和有机营养材料。
- **白杨**：速生、适合短轮伐和污染土地修复，可作为成片种植的木质生物质来源。
- **浮萍**：水生植物，可作为有机营养液、微生物培养和湿地生态的原料。
- **紫花苜蓿**：固氮作物，可用于高氮有机肥和温室营养液体系。
- **蓼蓝**：天然染料植物，为红麻和纤维复合料体系提供非矿物方向的材料分支。

### 生物候选

- **蚯蚓**：土壤和堆肥生态的核心生物，可促进腐殖质形成。
- **淡水蚌**：河流和湖泊生态指示物，可提供少量贝壳或钙质副产物。
- **蜗牛**：湿润农田和温室生态中的小型生物，以环境表现和装饰为主。
- **蚕**：连接桑树与天然纤维，为红麻纤维体系提供另一条材料路线。
- **水蚤**：水质指示生物，可用于未来的水体污染和微生物系统表现。
- **白蚁**：木质有机物分解者，可与森林、生物质和腐殖质循环关联。

### 生物群系候选

- **河岸湿地**：柳树、芦苇、浅水、泥土和湿地生物的综合生态环境。
- **盐碱湿地**：耐盐植物和高矿化水体的环境工业背景，可承接盐分处理。
- **工业荒原**：工业废弃和生态退化并存的地貌，用于表达污染后果。
- **红树林海岸**：海岸有机沉积、湿地生态和未来海水处理的自然入口。
- **高原风口**：强风和稀疏植被环境，为未来天气与自然能源系统预留空间。
- **地热谷地**：温泉、热泉和高温环境，可与耐热材料及热能利用关联。

### 世界生成结构候选

- **废弃气化厂**：旧炉体、煤气管线和储气设施，为生物质能源提供世界背景。
- **河流监测站**：水质检测、河流记录和环境工业线索的来源。
- **废弃温室**：残留培养槽、灌溉设备和种子，呼应温室系统。
- **露天采矿场**：破碎设施、轨道和废石堆，为 Processor、Separator 等设备提供工业遗迹背景。
- **废弃生物实验站**：培养罐、电极和样本，暗示 MFC 与生物工业的发展历史。
- **气象观测塔**：风向、降雨、温度和气压观测设备，为未来环境条件系统提供入口。

### 新维度候选

- **循环层**：以废料处理、资源再生和生态修复为主题的工业循环世界。
- **菌落界**：以微生物群落、生物膜和湿润生态为主题的远期世界。
- **深层工业遗迹**：埋藏在地下的旧工业文明遗址，重点是探索历史与设施，而不是单纯提供新矿物。

新维度应等到四大工业体系和现有世界内容成熟后再考虑，避免变成与主世界割裂的独立资源包。
