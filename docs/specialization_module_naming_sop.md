# 专业化模块命名 SOP

## 适用范围

本规范适用于 Poiesis 中改变机器工艺路线、输入输出逻辑或加工能力的专业化模块。性能模块不使用本规范。

## 显示名称格式

专业化模块的中文显示名称统一采用：

```text
模块：六字工艺术语
```

工艺术语部分必须正好六个汉字，并统一使用“模块：”前缀。显示名称不添加后缀。

## 命名原则

1. 使用真实工业、材料、流体或过程控制术语，避免单纯描述按钮功能。
2. 名称应能暗示模块改变的加工方向，但不必逐字翻译内部实现。
3. 优先使用“成形、解离、挤压、分选、富集、洗脱、流变”等工艺词。
4. 名称应具有专用工艺设备的感觉，避免与性能模块的“超频、效率”类名称混淆。
5. 物品 ID、英文显示名和内部能力 ID 不因中文命名调整而改变。
6. 专业化模块 tooltip 必须列出“可用机器：”，并使用每台机器单独一行的灰色条目排版。

## 当前标准名称

| 物品 | 中文显示名称 |
|---|---|
| Pressing Module | 模块：高压致密成形 |
| Grinding Module | 模块：颗粒机械解离 |
| Extrusion Module | 模块：连续塑性挤压 |
| High Shear Module | 模块：高剪切流变学 |
| Wet Separation Module | 模块：液相选择分离 |
| Rinsing Module | 模块：水相杂质洗脱 |
| Electrostatic Separation Module | 模块：静电富集分选 |

## 与性能模块的区分

性能模块继续使用直观的能力名称，例如“超频模块”“效率模块”，并使用独立的性能模块颜色。专业化模块则使用工艺术语和统一的“模块：”前缀。
