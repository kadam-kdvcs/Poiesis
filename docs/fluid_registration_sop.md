# 新流体注册与贴图 SOP

以后注册任何带流体桶的新流体，都必须同时完成注册、贴图和本地化，不能只添加一个流体对象。

## 注册对象

- 源流体（source）
- 流动流体（flowing）
- 流体方块
- 流体桶
- 流体方块模型/状态及对应资源
- 中英文语言键
- 必要的标签、创造栏入口和数据生成内容

## 流体贴图

需要上色的流体以 `textures/block/fluids/base.png` 或指定的灰度底图为素材，生成实际的彩色贴图。游戏内应直接引用生成后的彩色贴图，不依赖运行时纯色 Tint 作为最终显示。

仍需保留原贴图的明暗、纹理和动画帧。禁止将流体处理成单一纯色。

## 桶内容物贴图

使用 `textures/item/bucket_content.png` 作为桶内容物遮罩：

1. 直接取该流体实际彩色贴图中的像素颜色和纹理；
2. 按 `bucket_content.png` 的非透明区域裁剪；
3. 透明区域必须保持完全透明；
4. 不取平均色、不做纯色填充；
5. 输出到 `textures/item/bucket_content/<fluid_id>.png`。

如果需要生成完整桶贴图，则将上述内容物图叠加到桶底图上，并输出为 `textures/item/<fluid_id>_bucket.png`，供桶物品模型引用。合成桶贴图时，遮罩内的流体区域统一使用不透明像素，不继承流体原图的透明度；桶外区域仍保持透明。

## 动画与检查

- 流体动画贴图必须复制并适配对应的 `.mcmeta`；
- 流体类型、流体方块和流体桶必须分别有中英文名称；
- 流体方块的本地化键不能遗漏；
- 物品栏、世界中的流体、GUI 流体槽和桶物品都应引用真实的彩色资源；
- 生成资源后运行数据生成和构建检查，确认不存在 Missing textures。
